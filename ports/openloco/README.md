# OpenLoco

The AmigaOS 3.x OpenLoco port, build recipes, compatibility code, patches,
native Installer, probes and evidence live only in
[DalsinAI/amigaopenloco](https://github.com/DalsinAI/amigaopenloco).

AmigaChrome GamePorts retains this small integration pointer so catalogues and
automation can resolve the canonical port without carrying a second copy.
Consumers must use the immutable revision in `source.json`.

Original Locomotion data is not stored in either repository or its releases.
