# fheroes2

The AmigaOS 3.x fheroes2 port, build recipes, compatibility code, patches,
runtime-data tooling and evidence live only in
[DalsinAI/amigafheroes2](https://github.com/DalsinAI/amigafheroes2).

AmigaChrome GamePorts retains this small integration pointer so catalogues and
automation can resolve the canonical port without carrying a second copy.
Consumers must use the immutable revision in `source.json`.

Original Heroes of Might and Magic II data is not stored in either repository.
